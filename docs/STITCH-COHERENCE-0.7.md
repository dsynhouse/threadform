# Threadform 0.7 — stitch structure and Wilcom comparison

Review date: 7 September 2026. This update repairs unnecessary fragmentation in the generated sewing paths. It does not establish native Wilcom object compatibility or physical production qualification.

## What changed

Tatami rows are scheduled in connected bands and joined by travel inside the filled region. A polygon navigation mesh routes around holes and concavities when a straight connector would cross exposed fabric. Every proposed travel segment is checked against the source contours. Disconnected islands still require jumps. The same routing serves program split, square/double-square, contour, island coil, spiral, ripple, satin and their underlay where applicable.

Parallel satin now alternates needles between its two edges. The previous generator drew a full row followed by a short edge stitch, creating a ladder-like path. Raised satin uses successive connected passes of the corrected pattern. Same-edge spacing is explicitly labelled for satin and Columns A/B/C; spans above 7 mm are split and flagged for review. Centreline columns use shared miter joins so a tight turn does not fold the inside rail back over itself.

Automatic motif-run connections follow the source baseline, preserving its corners. Touching running paths join without an unnecessary jump. Explicit jumps/trims remain available between motifs and separate regions. Tie-ins are inserted at the first entry and after actual trims rather than every untrimmed jump. The connector setting no longer breaks each internal fill row into a separate sewing section.

The stitch progression inspector reports the current source object's sewing sections and total trims. Each source object remains editable as one object, including compound shapes with holes or several separate islands. Reopening and resizing a Threadform project retain that structure. Regenerate and export existing editable projects to obtain the corrected needle paths; existing machine files are not rewritten automatically.

All 32 available methods are included in the audit. Line methods use the same bent baseline in both audit columns; paired-rail satin uses a narrow straight column. Their repeated “solid/hole” entries are not additional hole tests. The comparison baseline is preserved in [stitch-coherence-baseline-0.6.json](qualification/stitch-coherence-baseline-0.6.json).

| Family                | Methods                                                                                          | Coherence policy                                                                                                                            |
| --------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Filled regions        | Tatami, program split, square, double square, contour, island coil, spiral, ripple               | Continuous contained travel within a connected region; jumps between separate islands                                                       |
| Satin                 | Parallel satin, raised satin, paired-rail satin (Columns A/B), centreline satin (Column C)       | Alternating edges, connected sections and underlay; long-span safeguards                                                                    |
| Runs                  | Run, double, triple, back, stem, chain, candlewick, coil run, motif run, zigzag, blanket, manual | Preserve the drawn path and repeat semantics; join coincident endpoints; honour deliberate motif gaps                                       |
| Open decorative fills | Wave, meander, coil fill, motif fill                                                             | Contained local or shared-boundary travel on Auto; separate motifs may retain jumps                                                         |
| Cross stitch          | Full, half, quarter, petite                                                                      | Preserve individual cross legs, English/Danish ordering and hole clipping; retain gaps where the current pattern requires separate sections |

Open fills can expose connecting runs. A lower jump count alone does not prove better appearance. Cross-stitch and motif sequencing still has room for optimization; this update does not claim Wilcom-equivalent routing for every pattern. Square/coil/chain effects are ordinary lockstitch paths, not chenille moss/needle-height or specialty-machine qualification.

## Wilcom comparison procedure

Download [stitch-structure-comparison.zip](qualification/stitch-structure-comparison.zip) for tatami with a hole, narrow satin, program split, square fill and a motif run. The package contains real DST/PES/JEF/EXP files and the original editable Threadform project. [tatami-wilcom-comparison.zip](qualification/tatami-wilcom-comparison.zip) contains the focused ring/islands comparison.

1. Open the extracted machine file at its saved physical size. Disable Objects/Outlines and Automatic Connectors for the unchanged-stitch baseline. For DST trim recognition, use three consecutive jumps.
2. Inspect needle penetrations and sewing progression: tatami rows form a joined fill sequence, satin crosses its width, and travel avoids the cutout. Ordinary line rendering can still display each stitch as a line.
3. Open a separate copy with Objects/Outlines recognition enabled to assess Wilcom's reconstruction. Review recognition ranges for tatami spacing and minimum stitch length. Compare actual spacing before copying a numeric density value between applications.
4. Preserve the original project and machine file. Record the Wilcom version, import options and any unexpected reconstructed objects before editing or regenerating inside Wilcom.

DST/PES/JEF/EXP in this app carry needle data, not native Wilcom EMB object metadata. A coherent sewing sequence can improve the input to object recognition, but it cannot guarantee that Wilcom reconstructs one editable Tatami object. Wilcom documents that reconstructed outlines and stitch types may differ from the original, especially fancy stitches. No Wilcom installation was available to verify that step. Native EMB export remains unavailable.

## Verification and remaining gates

The new 12-check coherence suite verifies all 32 generators, source-object preservation, continuity around holes, satin edge alternation, reverse program-split coverage, underlay/cover connections, Column C containment, motif baseline corners, intentional gaps, and rejection of disconnected navigation. It also compares every exported needle coordinate and colour change with an independent decoder for all four formats.

All **117 software checks pass**: geometry/workshop/digitizing/refinement 64, native output/reshape 13, tatami 8, coherence 12, local PostgreSQL account isolation 7, built-server/storage/UI components 13. TypeScript, lint and the production build also pass. The build continues to report an application chunk above 500 kB; initial-load performance remains an open release gate.

Physical sew-outs, a direct Wilcom import test, and browser/download qualification remain open. The browser service previously rejected preview access under its URL policy, so this update does not claim a new interactive browser pass. See [production readiness review](PRODUCTION-READINESS-0.6.md) for the wider outstanding gates, including live Supabase activation, complete calibrated manufacturer thread catalogues and machine qualification.

## Primary references

- [Wilcom run connectors](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Quality/connectors/Use_runs_as_connectors.htm): internal object segments differ from disconnected object components; travel can be visible in open stitching.
- [Wilcom satin structure](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Digitizing/stitches/Satin_stitching.htm): width-crossing stitches and long-span handling.
- [Wilcom tatami density](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Digitizing/stitches/Tatami_density.htm): spacing and mode-dependent density.
- [Wilcom machine-file Open options](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Production/convert/Open_machine_files.htm), [object recognition](https://docs.wilcom.com/embroiderystudio/e4/en/MainHelp/Production/convert/Object_recognition.htm): stitch data, reconstruction and its limits.
- [Mapbox Earcut](https://github.com/mapbox/earcut): polygon triangulation with holes. Threadform normalizes contours and independently validates returned route segments.
- [pyembroidery](https://github.com/EmbroidePy/pyembroidery): independent decoding oracle, version 1.5.1.
